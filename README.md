# Apparato cardiocircolatorio — ambiente digitale di studio

Trasformazione integrale della sbobina «Anatomia 1 — Apparato Cardiocircolatorio» in un sito statico in italiano.

## Pubblicazione su GitHub Pages

1. Caricare l’intera cartella del progetto in un repository GitHub.
2. Aprire **Settings → Pages**.
3. In **Build and deployment**, scegliere **Deploy from a branch**.
4. Selezionare il branch **main** e la cartella **/docs**.
5. Salvare.

Non sono necessari Node, compilazione, database, API, token o account. Il progresso dello studente resta nel browser mediante `localStorage`.

## Contenuti di verifica

- `CONTENT_COVERAGE.md`: mappa pagina per pagina.
- `IMAGE_COVERAGE.md`: inventario delle immagini incorporate.
- `QA_REPORT.md`: metriche e controlli finali.
- `source-map.json`: tracciabilità macchina PDF → sito.
- `docs/`: sito completo pronto per GitHub Pages.
